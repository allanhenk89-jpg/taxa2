Política de Privacidade — Taxômetro

Última atualização: 2025

1. Coleta de dados

O Taxômetro não coleta, transmite ou compartilha dados pessoais.

2. Armazenamento local

Todos os dados (taxas e comparações) ficam exclusivamente no dispositivo do usuário, armazenados de forma criptografada (AES-256-GCM). Nunca saem do aparelho.

3. Análise IA

O recurso de Análise IA envia apenas as taxas configuradas (sem dados pessoais) para a API da Anthropic via um servidor proxy seguro, exclusivamente para gerar a análise comparativa.

4. Anúncios

O app usa o Google AdMob para exibir anúncios. O Google pode coletar dados conforme sua política em policies.google.com/privacy.

5. Permissões

O app não solicita câmera, microfone, localização ou contatos.
